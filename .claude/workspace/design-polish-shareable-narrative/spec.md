# Spec — Design Polish + Shareable Narrative (T08)

> **소급 문서.** CLAUDE.md §1은 코드 이전에 spec/design 승인을 요구하지만 T08은 이를 건너뛴 채 구현됐다.
> 이 문서는 `/code-review xhigh` 지적(#12)에 따라 확정된 사항을 사후에 기록한 것이며,
> 앞으로의 변경은 다시 spec → design → implementation 순서를 따른다.

## 배경 / 문제

Soul Map은 T01–T07에서 관측·판단·거버넌스 레이어를 갖췄다. T08의 목표는 이걸 **외부에 공유 가능한 데모** 수준으로 끌어올리는 것이다.

초기 구현(커밋 `ee5d55a` 이전 작업분)은 시각적으로는 정돈됐지만, 리뷰에서 **테스트가 통과하는데도 브라우저에서는 성립하지 않는** 결함이 15건 확인됐다. 핵심 원인 두 가지:

1. **좌표계 불일치** — 연결선은 `viewBox="0 0 100 100"` 정규화 공간에, 노드는 `left/top` 퍼센트로 배치돼 두 레이어가 서로 다른 픽셀 위치를 가리켰다.
2. **시각 계약을 CSS 원문 정규식으로 검증** — 선언 순서만 바꿔도 실패하고, 실제 시각 버그는 전부 통과시켰다.

## 목표 (Goals)

- 별자리의 연결 화살표가 **실제로 노드에 닿고, 보이고, 방향이 맞는다.**
- 좁은 화면에서 가로 스크롤이 발생하지 않고, 노드 카드가 겹치지 않는다.
- autonomy 막대가 데이터 전 범위를 구분 가능하게 표현한다.
- 그래프의 연결 관계가 안내 없이 사라지지 않는다.
- 시각 계약 테스트가 **포맷 변경에는 둔감하고 실제 회귀에는 민감**하다.
- 생성 산출물이 워킹트리를 더럽히지 않는다.

## 비목표 (Non-goals)

- 방사형 배치 자체의 재설계(예: 모바일 전용 리스트 레이아웃)는 하지 않는다. 최소 폭 + 가로 스크롤로 해결한다.
- 기본 테마와 Trading Room 리스킨을 하나의 스타일시트로 통합하는 리팩터링은 하지 않는다. (약 30건의 의도된 오버라이드가 있으며, 별도 과제다.)
- 실제 브라우저 스크린샷 회귀(visual regression) 도입은 하지 않는다. jsdom + 캐스케이드 모델로 커버 가능한 범위까지만 다룬다.

## 수용 기준 (Acceptance Criteria)

- [x] 연결선 양 끝이 두 개의 서로 다른 노드 카드 경계에 붙는다.
- [x] 화살촉이 카드 뒤에 가려지지 않는다.
- [x] 화살촉이 실제로 채워져 렌더된다(투명 삼각형 아님).
- [x] 양방향 연결의 시작 화살촉이 출발 노드를 향한다.
- [x] 그래프의 모든 간선이 렌더된다. 선택과 무관한 간선은 감추지 않고 흐리게 둔다.
- [x] 노드가 아무리 가까워도 화살표가 역방향으로 뒤집히지 않는다.
- [x] ≤980px에서 어떤 패널도 2번째 그리드 열을 요구하지 않는다.
- [x] 데스크톱·모바일 모두에서 노드 카드가 겹치지 않는다.
- [x] 서로 다른 autonomy 값이 같은 높이로 뭉개지지 않는다.
- [x] 효과가 없는 `@media` 오버라이드가 남아 있지 않다.
- [x] `src/data/projectActivity.ts`가 git에 추적되지 않는다.
- [x] detail 패널의 섹션 제목이 중복 렌더되지 않는다.
- [x] 접근성 이름을 지어내지 않고 기존 제목을 `aria-labelledby`로 가리킨다.

## 리스크

| 리스크 | 완화 |
|---|---|
| jsdom에는 레이아웃 엔진이 없어 시각 회귀를 잡지 못한다 | 좌표는 순수 함수로 뽑아 픽셀 단위로 단위 테스트하고, CSS는 특이도·소스순서를 계산하는 캐스케이드 모델로 검증한다 |
| 별자리 최소 폭을 강제하면 좁은 화면에서 가로 스크롤이 생긴다 | 겹쳐서 읽을 수 없는 것보다 낫다고 판단. 스크롤은 패널 내부로 한정해 문서 전체는 가로로 넘치지 않게 한다 |
| 생성 파일을 추적 해제하면 새 클론에서 타입 에러가 난다 | `predev`/`prebuild`/`pretest`가 항상 먼저 생성한다. 생성기에는 `~/.hermes`가 없을 때의 fallback이 있다 |

## Reviews

- **designer (self_reviewed)** — 연결선을 감추는 대신 흐리게 두는 쪽으로 바꿨다. 정보 손실보다 시각 밀도를 택했다. 별자리 최소 폭 720px은 카드 164×104 기준 겹침 여유 +9px에서 산정.
- **security (self_reviewed)** — `src/data/projectActivity.ts`는 로컬 `~/.hermes` 세션 타임스탬프에서 파생된다. 추적 해제로 개인 활동 기록이 커밋되는 경로를 차단했다. 외부 호출·네트워크 변경 없음.
- **qa (self_reviewed)** — 15건 전부 RED를 먼저 확인한 뒤 GREEN으로 넘어갔다. 리뷰가 놓친 3건(데스크톱 노드 겹침, 죽은 `.app-shell` 패딩 오버라이드, 죽은 `.constellation-panel` min-height)을 테스트가 추가로 잡았다.
